# 003 Store, play ledger and SyncPlays: tasks

Legend: `[P]` = parallel-safe (disjoint crates) · each task = one commit · every behaviour task starts with a failing test.

Prerequisites from the sibling specs:
- **001** provides the crate skeletons, all pins, `wolluf-core` with `Clock`, `VersionKey`, `PlayId`, `DotNetTicks`/`FileTime`, `BlobSha256`, `xtask check-layers` (incl. the L5 restricted-deps table), and `panic = "unwind"` in every profile (the per-item `catch_unwind` needs it).
- **002** provides the scores.db, osu!.db and `.osr` header codecs (raw name bytes, raw `i64` ticks, `OnlineId::positive`), `ReplayFileName::parse` (002 T5), install detection, and `test-support` builders for these three formats.
- **005 T3** provides `AppError` (`crates/app/src/errors.rs`) before T13.

`export PATH="$HOME/.cargo/bin:$PATH"` before any verify command.
