# 001 Workspace foundation: tasks

Legend: `[P]` = parallel-safe (disjoint crates) · each task = one commit.
All commands assume `export PATH="$HOME/.cargo/bin:$PATH"` and run from the repo root. T1 is orchestrator-only (root `Cargo.toml`). After T1 there are two lanes: core (T2–T8, `crates/core`) and xtask (T9–T13, `xtask/` + `deny.toml`). `[P]` on T9–T12 means parallel **with the core lane**; inside the xtask lane they are sequential (same crate). ADR tasks T16–T24 touch only `docs/adr/` and can run any time after T1, in parallel with each other.
