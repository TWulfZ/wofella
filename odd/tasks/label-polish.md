# Label screen polish and app shell

Branch `feat/label-polish` from `feat/label-navigation` @ 6e7976f (stacked on PR #17) · opened 2026-10-06

## Objective
Pilot feedback on the PR #17 build, round 2: a compact answer bar, notes that end their travel on the skin's hit position, a chart timeline, a lazer-style header (blurred background, star rating in osu! colours), axis sections as collapsible cards under RICE/LN, a hand-layout preference that drives the previews, and "coming soon" Skill and Recommendations pages.

## Problem and why
Pilot requests (2026-10-06, with screenshots):
- The sticky answer bar takes too much room: one truncated line, expanding to ~3 lines on hover/focus; flags stay in the bar and also show in the answer summary.
- Playfield: notes travel to the bottom edge instead of the skin's hit position, so they end below the judgement line and the scroll looks slower; the skin's hit position must define where notes land and the scroll distance.
- A timeline to move through the chart being inspected; the widen/narrow/shift buttons are confusing and go away (the timeline replaces shifting; the sampler's window length stays).
- Header like osu!web / osu!trainer: blurred map background behind title, artist, mapper, difficulty name and tags, plus the star rating with osu!'s difficulty colour spectrum, to recognise maps already played.
- Pattern panel: each axis as an eye-catching rectangular card that opens to its patterns; RICE and LN as master sections; searching opens the sections with matches (the inverse of the previous collapse-on-search).
- Hand layout (thumb side) is a user preference; previews and the playfield draw the hand split from it instead of always the right-thumb layout.
- Skill and map recommendations are future features; show them as "coming soon" pages to set expectations.

## Scope
- Authorized: `crates/chart` (pure `[Events]` background-name extraction), `crates/source-osu` (read-only background read + sniff; mania no-mod SR kept from osu!.db), `crates/store` (catalog `stars` column, `CACHE_SCHEMA_VERSION` bump; settings repo access), `crates/app` (labeling/library/settings services + DTOs), `apps/desktop/src-tauri` (appended commands), `bindings.ts`, `apps/desktop/ui/src/**` (label, playfield, settings, nav, new routes, locales), ADR 0018 amendment.
- Out of scope: computed SR (planned difficulty crate), re-segmenting the library under the preferred layout (segments stay on the profile default), animated previews, the session-labelling flow.

## Constraints
- D9/D2: source-osu read-only; the `[Events]` parse is a pure function in `chart`; background read on demand by md5 only (ADR 0018/0019 pattern: typed command, base64 `data:` URL under the current CSP, bytes sniffed, byte cap in params D17).
- cache.db is disposable: bumping `CACHE_SCHEMA_VERSION` rebuilds it (ADR 0003); SR is stable's cached no-mod mania value, `null` when absent.
- The layout preference lives in user.db `settings`; examples stay validated under the profile default and are only drawn with the preferred layout's hand split.
- ADR 0009: appended commands, no 64-bit fields, bindings regenerated by one owner per stage.
- UI: tokens only, motion-safe, focus states, a11y names; i18n en + es; the answer bar keeps the region name "Answer".
- TDD: strict. Runners: `cargo nextest run -p <crate>`, `pnpm -C apps/desktop/ui test`.

## Acceptance criteria
- Answer bar: one truncated line by default, full (~3 lines) on hover or focus-within, flags visible in the summary and toggles in the bar → AnswerBar tests.
- Playfield: a note reaches the skin's hit position exactly when its time is now; nothing is drawn as "landing" below it; scroll speed follows osu!'s distance to the hit position → playfield projection tests.
- Timeline: shows the chart span with a density strip, the current window and own labelled spans; click/drag moves the window (`label_move_window`) → service + UI tests.
- Header: blurred background (fallback gradient), title/artist/mapper/version/tags, star rating with osu! colours → service (SR, background) + UI tests.
- Reshape buttons removed → UI tests.
- Pattern panel: RICE/LN master sections, axis cards collapsed by default, open on click, search opens matching sections → PatternGrid tests.
- Hand layout setting persisted and applied to previews and playfield → service + UI tests.
- Skill and Recommendations "coming soon" pages reachable from the nav → route tests.
