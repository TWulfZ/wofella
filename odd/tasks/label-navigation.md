# Label navigation and structured answers

Branch `feat/label-navigation` from `feat/pattern-previews` @ 666a873 (stacked on PR #16) · opened 2026-10-06

## Objective
The Label screen has a resizable pattern panel, a top toolbar (Previous · Next · Random · Now playing · Skip), a pattern grid that collapses to a compact horizontal view, and an answer bar pinned to the bottom that only accepts patterns chosen from the taxonomy (chips + a "+" picker), never free text.

## Problem and why
- Pilot feedback on the PR #15/#16 builds (2026-10-06): the answer field reads like a search box and is not pinned at the bottom; free typing risks dirty labels; the pattern panel is too narrow on large monitors; the preview cards take too much room when searching.
- Pilot decisions (2026-10-06): Previous/Next walk the windows already shown in the session (Next on the newest samples a new one); Skip discards the current window and counts it as skipped; Random takes any chart of the keymode outside the stratified plan; Find is dropped in favour of "Now playing" (the map osu! stable is playing, else the last one the self player finished).
- Now playing without tosu or memory reading: stable's window title is `osu!  - Artist - Title [Difficulty]` while playing (to verify on the pilot's machine), readable through `tasklist /v` on Windows and from WSL (checked: the CSV has a "Window Title" column); otherwise the newest self replay in `Data/r` (`<md5>-<FILETIME>.osr`, research 03 l.161). tosu stays an optional F5 component (ADR 0008).
- Structured answers: the UI builds `{patterns: ids, noPattern, flags, thumb}` directly from taxonomy ids; the text grammar stays only in the CLI (`wolluf label`). The backend already validates ids against the taxonomy (`LabelingService::submit`).

## Scope
- Authorized: `crates/app/src/features/labeling` (window-at-chart, random and now-playing service methods), `crates/source-osu` (window-title read on the existing tasklist/process probe, newest replay lookup; read-only, no new dependency), `apps/desktop/src-tauri` (new `label_*` commands, appended), `bindings.ts`, `apps/desktop/ui/src/features/label/**`, `apps/desktop/ui/src/shared/ui/**` (resizable handle, popover/command primitives if needed), label locales, ADR 0018 amendment.
- Out of scope: chart header media (`feat/chart-header-media`), per-song session prompts (`feat/session-labelling`), Linux/wine window titles (falls back to the last replay), sampler stratification changes.

## Constraints
- Sampler determinism: Random and Now playing do not consume a stratified round; their anchors still join `exclude` so the plan never repeats them.
- ADR 0005: the last-replay fallback only uses replays whose player is a self alias; before the self profile exists it returns nothing.
- D9: source-osu stays read-only; window-title probing is on-demand (button press), never a timer.
- ADR 0009: commands `label_*`, appended, no 64-bit fields; bindings regenerated by a single owner.
- UI: the answer bar is sticky at the bottom of the panel with reserved space so the grid never hides behind it; the "+" picker is a searchable list of taxonomy patterns (keyboard: type to filter, arrows, Enter), selected patterns are removable chips; Enter saves, Esc clears; no global type-to-answer; panel width persisted per viewer (localStorage via `prefs.ts`), draggable and keyboard-resizable (arrow keys on the separator, `role="separator"` with aria-valuenow); collapse: expanded by default, typing in the pattern search switches to compact, clearing it restores expanded unless "Always collapsed" is checked (persisted).
- TDD: strict. Runners: `cargo nextest run -p wolluf-app`, `cargo nextest run -p wolluf-source-osu`, `pnpm -C apps/desktop/ui test`.
- Delivery: ~900 authored lines forecast (LabelScreen tests dominate); stacked PR on #16.

## Acceptance criteria
- `label_window_at(keymode, md5, seed)` returns a window inside the given chart (or a clear error for an unknown/unparsed chart) → app service test.
- `label_random(keymode, seed, round, exclude)` returns a window from any eligible chart, deterministic for its inputs, never overlapping `exclude` → app service test.
- `label_now_playing(keymode)` resolves the osu! window title to a catalog md5, else the newest self replay, else null → source-osu title-parser tests + app service tests with a fake probe.
- Previous/Next/Skip/Random/Now playing behave as the pilot decided; a saved window revisited via Previous shows its saved answer and offers Undo → LabelScreen tests.
- The answer bar is pinned to the bottom, only taxonomy patterns can be added (chips + "+"), and no free-text answer path remains in the UI → LabelScreen tests.
- The pattern panel resizes by drag and keyboard and remembers its width; the grid collapses while searching and when forced → tests.
